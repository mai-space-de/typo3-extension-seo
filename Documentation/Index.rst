===========
maispace/seo
===========

:Extension key:

----

A TYPO3 extension that adds structured data (JSON-LD), Open Graph meta tags,
canonical URL rendering, and robots meta tag control to page properties.
Includes Fluid ViewHelpers for frontend output and a backend module for SEO
statistics.

**Requires:** TYPO3 13.4 LTS · PHP 8.2+
